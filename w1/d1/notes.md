## gdb

~gdb - Debugger that allows you to see what is going on inside another program while it executes.


### Commands

~**lay next** - Switch to next layout on the TUI (Text User Interface) mode.

~**break** - Set a new breakpoint.

~**run** - Run the program to be debugged.

~**step** - Go to next instruction (source line), diving into function.

~**next** - Goes to the next instruction (source line) but won't dive into functions.

~**finish** - Continue until the current function returns.

~**continue** - Continue normal execution.

~**ref** - Refresh screen.

### Stepping

__step__, __next__, and __finish__ are used to step into, over, and out.
