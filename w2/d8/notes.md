~Pointer: variable that stores the memory address of another variable.

~&: address operator (reference operator). It returns the address of a variable. Can be read as "address of".

~*: When you create a pointer variable its called 'The Pointer Declarator'. When
dereferencing is called indirection operator (dereference operator). Can be read as "value pointed by".

~Referencing: it means to access the memory address of a variable.

~Dereferencing: it means to access the variable stored at a memory address.
