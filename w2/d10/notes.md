~Buffer: sequential section of memory that is used to temporarily store some data that is
being transferred from one place to another.

Buffer Memory is required to synchronize data transfer by temporarily storing it until its ready
to be transferred or processed.

&Example: you have to store a multi-digit number in a variable, so you will have to write it
digit by digit. If there is no buffer memory, the first digit you enter will directly be stored
inside the variable and you won't be able to store the rest of the digits.
